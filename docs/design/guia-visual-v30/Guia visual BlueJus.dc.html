Referência PJe

Familiar para quem usa o PJe, sem perder a identidade BlueJus
O PJe é o sistema do tribunal; o BlueJus é a plataforma do advogado. Herdamos o que o advogado já faz no automático (onde ficam as coisas, os nomes, a ordem dos campos) e mantemos o que é nosso (cores, tipografia, etiquetas, cards). Onde o padrão do PJe prejudica leitura ou acessibilidade, adaptamos.
