## Observações (riscos, conflitos Designer × sistema, dúvidas)
1. **Sem P0.** A rota de impressão confere tenant e permissão; o editor não grava marcação fora do sanitizador. O protótipo sanitiza no cliente e aceita `style` inline e `img` data URL — **não** copiar essa política (o mestre e o YAML já registram o porquê).
2. **Conflito de atalho no desenho:** o editor usa Ctrl+K para link e a página usa Ctrl+K para a busca global (`onBuscaG` escuta em `window`, e o editor só chama `preventDefault`, sem `stopPropagation`) — no protótipo as duas coisas disparam juntas. Quem decidir D-BARRA e D-EDITOR precisa escolher um dono para o Ctrl+K (sugestão: dentro do editor, link; fora, busca).
3. **Tab disputado:** se o EDT-015 (sugestões) entrar, Tab/Enter passam a ser disputados com a lista de @menção; a lista de @ tem de vencer quando aberta.
4. **Auditoria de impressão/download** (dc:4561 audita "download PDF"): não confirmei se o `audit_log` tem canal para evento sem entidade. Se não tiver, o registro da impressão é regra nova — perguntar antes de criar.
5. **Metas:** o desenho não usa `<bj-editor>` nas metas (só os contextos expedientes, financeiro, observacoes). "Copiar link" da meta está no mestre como AUTÔNOMO, mas é da área Metas (`_metas.html.twig:25-27`) — não contei aqui.
6. **"Encaminhar via Chat I.A" / "Enviar no Chat I.A"** nos mesmos menus (dc:2929, 6459, 6462) são D-CONNECT/D-IA: ficaram para a área do Registro/Processo.
