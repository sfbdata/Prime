## Para o cliente
- Preparamos o plano para cada escritório escolher as ferramentas que usa. O dono do escritório vai poder ligar e desligar ferramentas (Expediente, Cobranças, Cálculo, Kanban, Assinatura, Ponto, Voto e I.A.) no Meu Perfil, sem perder dados ao desligar. Também vai ser possível criar uma conta só com o BlueJus Voto, para assembleias de condomínio.
